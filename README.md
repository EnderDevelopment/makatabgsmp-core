# MakataBGSMP Core

MakataBGSMP Core is a professional Minecraft plugin designed for survival multiplayer servers. It features a custom scoreboard, player commands, an economy system, ranks and permissions, welcome messages, anti-grief protection, player protection, a starter kit, death messages, and is optimized for performance. The plugin is built for Paper 1.21.x and is compatible with Aternos hosting.

## Install

1. Download the latest release of MakataBGSMP Core from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. After installation, the plugin will automatically enable and display a custom scoreboard for all players.
2. Use the provided commands to manage your server:
   - `/spawn` - Teleport to the spawn point.
   - `/sethome` - Set your home location.
   - `/home` - Teleport to your home location.
   - `/delhome` - Delete your home location.
   - `/tpa` - Send a teleport request to another player.
   - `/tpaccept` - Accept a teleport request.
   - `/back` - Return to your previous location.
   - `/msg` - Send a private message to another player.
   - `/bal` - Check your balance.
   - `/pay` - Send money to another player.
   - `/baltop` - View the top balances on the server.
